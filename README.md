## 📥 安装使用

### 适用于 TRAE / 支持 SKILL.md 的 AI 助手

**方法一：手动安装（推荐）**

1. 下载本仓库的 `SKILL.md` 文件
2. 放到你的 TRAE skills 目录下：
   - Windows: `%APPDATA%\TRAE SOLO CN\ModularData\ai-agent\work-mode-projects\<项目名>\.trae\skills\ai-prompt-wizard\`
   - macOS: `~/Library/Application Support/TRAE SOLO CN/...`
3. 重启 TRAE，新对话中即可调用

**方法二：Git 克隆**

```bash
cd 你的项目目录/.trae/skills/
git clone https://github.com/UIddd-du/ai-prompt-wizard.git
```

安装完成后，在对话中说"帮我写提示词"或"给剧本拆成分镜"即可触发。

## 📦 Word 文档自动生成

每次处理剧本自动生成 `.docx` 文档，包含：

- **封面页**：剧名 + 风格版本 + 生成日期
- **角色设定锚点**：每个角色的定妆提示词 + 负面词 + 参数
- **分镜表**：12列完整版，按幕分组，表头锁定
- **创作说明**：节奏设计 + 风格统一 + 一致性保障
- **音效设计说明**：BGM 推荐 + 音效工具建议
- **制作流程建议**：5 步制作法 + 一致性小技巧

**视觉规范：**
- 横向 A4，0.67 英寸窄边距（12列也放得下）
- 表头深蓝底白字，奇偶行交替底色
- 每页顶部自动重复表头（翻页也能看到列名）
- 微软雅黑中文字体，表格 8pt 紧凑清晰

## 🎯 核心设计理念

### 1. 中文优先
所有提示词默认中文输出，国人看得懂、改得动、用得顺。同时提供英文对照版兼容海外平台。

### 2. 风格即一切
不再默认生成"真人版"。先问风格再生出，7 种风格从视觉到镜头语言到音效全方位适配。

### 3. 开箱即用
提示词不是"参考思路"，是**可以直接复制粘贴**的成品。每一列的内容都针对对应 AI 工具优化过。

### 4. 全流程覆盖
从角色定妆 → 关键帧 → 动态视频 → 音效配乐 → 后期剪辑，一条龙全包。

## ❓ 常见问题 FAQ

### Q1：7 种风格怎么选？
看你的剧本题材和想要的感觉：
- **真人写实版**：剧本偏现实、文艺、悬疑，想要电影感
- **动漫/漫剧版**：青春、恋爱、热血、奇幻，受众偏年轻
- **古风水墨版**：古装、仙侠、武侠、山水田园
- **赛博朋克版**：科幻、未来都市、动作、反乌托邦
- **3D动画版**：合家欢、喜剧、冒险、童话
- **绘本插画版**：治愈系、儿童故事、温暖童话
- **概念艺术版**：奇幻史诗、大场景、游戏美术

### Q2：生成的提示词可以直接用吗？
可以。每一列的提示词都是针对对应 AI 工具优化的成品，复制粘贴即可使用。如果效果不理想，可以在基础上微调关键词。

### Q3：支持哪些 AI 平台？
文生图：可灵、即梦、Seedance、FLUX、Midjourney、Stable Diffusion
视频：可灵、即梦、Seedance、Veo、Runway Gen-3
音效：可灵音效、AudioCraft、Stable Audio

### Q4：提示词太长会不会有问题？
不会。现在的 AI 工具基本都支持长提示词，越详细反而效果越精准。如果平台有 token 限制，可以取"核心关键词"部分使用。

### Q5：为什么要先问风格再生成？
不同风格的画面差异非常大（真人 vs 动漫完全是两个方向），默认生成容易不符合预期。先确认风格，可以一次生成到位，节省反复修改的时间。

### Q6：可以自定义风格吗？
可以。7 种风格是预设模板，你可以在生成后说"改成 XX 风格"，系统会基于现有内容做风格迁移。

### Q7：Word 文档用什么打开？
微软 Word、WPS、苹果 Pages、Google Docs 都可以正常打开和编辑。
